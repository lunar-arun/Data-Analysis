# 🧠 Data Analysis with Python: Pandas, NumPy, Matplotlib, and Seaborn

Welcome to the **Data Analysis with Python** training repository!  
This repo is designed for beginners and intermediate users looking to enhance their skills in data analysis using Python's most powerful libraries:

- 📊 **Pandas** for data manipulation and analysis  
- 🔢 **NumPy** for numerical computing  
- 📈 **Matplotlib** for data visualization  
- 🌈 **Seaborn** for statistical plotting  

---

## 📚 Course Structure

The training is organized into modular, hands-on notebooks covering the following topics:

### 1. **Getting Started**
- Installing required packages
- Jupyter Notebook basics
- Introduction to datasets

### 2. **NumPy Essentials**
- Arrays, indexing, and slicing
- Vectorized operations
- Broadcasting and basic statistics

### 3. **Pandas Fundamentals**
- Series and DataFrames
- Data selection and filtering
- Handling missing data
- Grouping and aggregation
- Merging and joining datasets

### 4. **Data Visualization with Matplotlib**
- Line, bar, scatter, and histogram plots
- Customizing plots (labels, titles, legends)
- Subplots and figure sizing

### 5. **Statistical Visualization with Seaborn**
- Distribution plots (histplot, kdeplot)
- Categorical plots (boxplot, violinplot)
- Correlation and regression plots
- Styling and themes

### 6. **Projects & Case Studies**
- Exploratory Data Analysis (EDA) project
- Real-world datasets
- Final project with complete data workflow
